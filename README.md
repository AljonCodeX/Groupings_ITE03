## Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/AljonCodeX/Groupings_ITE03.git
   ```
2. Import the database file from the `database/` folder into MySQL (once schema is created).
3. Run the project using a local server (e.g. XAMPP) and open the `pages/` folder in your browser.
